1. Dynamic Lifecycle & Execution Loop

Tier 1 · Executive summary

The 4-beat loop

Observe joints, root pose, goal, velocity → Infer with ONNX → Apply targets to PhysX joint drives → Score with the reward function and check for termination. Every 0.02 s (FixedUpdate).

Tier 2 · Basic overview

Loop steps and message flow

  1. C# Agent (Agent_Creature) packs an observation vector from ArticulationBody.jointPosition, jointVelocity, root up, position.y, goal direction & distance, and root velocity.
  2. Sentis runs the ONNX policy on Burst and returns continuous actions a ∈ [-1, 1]^N.
  3. Each action becomes an ArticulationDrive.target in degrees (revolute) or metres (prismatic) before the next PhysX step.
  4. Reward_WormLoco.Step computes potential-based progress, efficiency penalty, upright bonus, and constant time cost; Agent_Creature fires terminal checks (goal hit / out-of-bounds / no-progress) and either ends the episode or loops back.
Figure L1 · Lifecycle & execution loop — simple (conceptual)
Tier 3 · Complete specification

Detailed pipeline (tensors, memory, Sentis, PhysX)

The detailed diagram breaks the loop into four runtime layers: C# packing, ONNX inference, PhysX solve, and the buffer / reset loop. Key invariant: actions are applied only in FixedUpdate because ArticulationBody.Solve consumes targets at the same cadence as the simulation step (0.02 s).

Cadence and timing

  • Time.fixedDeltaTime = 0.02 · Physics.gravity = (0, -9.81, 0) · vSyncCount = 0, targetFrameRate = 60
  • DecisionRequester.DecisionStep = 5 on inference racers means the policy runs every ~0.10 s, but PD targets are held continuously by the drive between decisions.
  • Training cadence: the trainer runs num_epoch = 3 passes per buffer with a batch_size = 2048 gradient step.

NaN firewall

Reward_WormLoco.Step sanitizes currentDistance, normalizedTorque, and uprightDot before any arithmetic. One exploding body must never feed NaN into a sensor, which would abort the Academy step for all agents sharing the environment.

2. Tensor Blueprint & Actuator Map

Tier 1 · Executive summary

What the policy sees and what it controls

Input: per-joint position + velocity (2·N), root up, height, goal direction, goal distance, root velocity → N·2 + 11 floats. Output: one continuous value per joint, in [-1, 1], scaled into an ArticulationDrive.target.

Tier 2 · Basic overview

Per-creature observation shape

obs = [
  joint_position_normalized (N),
  joint_velocity_normalized (N),
  root.up (3),
  root.position.y (1),
  goal_dir_local (3),
  goal_distance / 20 (1),
  root_velocity_local / MAX_ROOT_SPEED (3)
]   // total = N*2 + 11

With terrain probes enabled, four look-ahead raycasts add +4 floats. Each value passes through Safe() so NaN/Infinity collapse to 0.

Network

Two fully-connected layers of 256 units with tanh activations, fed through an optional LSTM(128) for memory. Output heads emit per-action means; SAC additionally emits log_sigma.

3. Sensor Perception & Reward Tree

Tier 1 · Executive summary

Reward = progress − effort + upright − time

The composite reward favors forward motion, discourages waste of torque, rewards staying upright, and adds a constant per-step cost so faster finishes win. Three terminal conditions: reach the goal, fall out of bounds, or 20 s without progress.

Tier 2 · Basic overview

Components (per step)

SignalFormulaSignWeight
Progress (extrinsic)Δd × PROGRESS_SCALE+1.0
Efficiency penalty−ENERGY_PENALTY × torque_norm−0.05
Upright bonusUPRIGHT_BONUS × max(up·ŷ, 0)+0.02
Time penaltyconstant−0.002

Terminal conditions

  • Goal: d ≤ 0.5 m → +10 bonus, EndEpisode()
  • Out-of-bounds: y < −1 → −1, EndEpisode()
  • No-progress: 1000 steps (~20 s) without best-distance improvement → EpisodeInterrupted()

Tier 3 · Complete specification

Reward shaping constants (Reward_WormLoco)

PROGRESS_SCALE         = 1.0
GOAL_REWARD            = 10.0
OUT_OF_BOUNDS_REWARD   = -1.0
GOAL_RADIUS_METERS     = 0.5
NO_PROGRESS_LIMIT_STEPS = 1000     // 20 s @ 0.02 s
MAX_STEP_DELTA_METERS  = 0.2       // physics glitch clamp
ENERGY_PENALTY_SCALE   = 0.05
UPRIGHT_BONUS_SCALE    = 0.02
TIME_PENALTY           = 0.002     // ≈ 6 / full 3000-step episode

StatsRecorder telemetry (training only)

When Academy.IsCommunicatorOn, Agent_Creature writes:

stats.Add("Reward/Progress",           LastProgressReward)
stats.Add("Reward/EfficiencyPenalty",  LastEfficiencyPenalty)
stats.Add("Reward/UprightBonus",       LastUprightBonus)
stats.Add("Reward/TimePenalty",        -TIME_PENALTY)

Inference-only racers never pay this cost — hundreds of bots in a race do not record stats.

NaN firewall invariants

  • currentDistance: NaN/Inf → fall back to _previousDistance (no zero-delta that would still poison progress).
  • normalizedTorque: NaN/Inf → 0 (no efficiency penalty).
  • uprightDot: NaN/Inf → 0 (no upright bonus).
  • delta ternary clamp passes NaN through; the stored _previousDistance is reset explicitly when delta is NaN.
